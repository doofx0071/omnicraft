## Stack

| Layer    | Tech                                            |
| -------- | ----------------------------------------------- |
| Client   | {{clientFramework}} + Vite + {{clientLanguage}} |
| API      | {{backendFramework}} + TypeScript (`server/`)   |
| Database | SQLite via {{orm}}                              |

npm workspaces: `client/` and `server/` share the root `package.json`.

## Commands

| Command              | What it does                        |
| -------------------- | ----------------------------------- |
| `npm run dev`        | Run client and server together      |
| `npm run build`      | Build client and server             |
| `npm run start`      | Start the built API server          |
| `npm run db:push`    | Push schema changes to the database |
| `npm run db:migrate` | Create/apply a migration            |
| `npm run db:seed`    | Insert sample data                  |

## Ports

- API server: `3000` (`PORT` in `server/.env`)
- Client dev server: `5173` — proxies `/api` requests to the API server

## Database

SQLite — no Docker needed. The database file is created from `DATABASE_URL`
in `server/.env` (default `file:./data/app.db`, auto-created on first run);
apply schema changes with `npm run db:push`.

## Environment

`server/.env` (created from `server/.env.example` at scaffold time) holds
`DATABASE_URL`, `PORT`, and `CORS_ORIGIN`. The server validates it with zod at
startup. `SKIP_ENV_VALIDATION=1` bypasses validation for CI/build-time steps
that import the app without credentials — never set it in production.
