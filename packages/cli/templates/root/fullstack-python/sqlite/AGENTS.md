# AGENTS.md

Guidance for AI coding agents working in this repository. Generated by OmniCraft.

## Stack

| Layer    | Tech                                                        |
| -------- | ----------------------------------------------------------- |
| Client   | {{clientFramework}} + Vite + {{clientLanguage}} (`client/`) |
| API      | FastAPI + SQLAlchemy + Alembic (`server/`, managed with uv) |
| Database | SQLite                                                      |

The Python server runs through [uv](https://docs.astral.sh/uv/); the root
`package.json` scripts wrap the uv commands.

## Commands

| Command              | What it does                   |
| -------------------- | ------------------------------ |
| `npm run dev`        | Run client and server together |
| `npm run dev:server` | Run only the FastAPI server    |
| `npm run build`      | Build the client               |
| `npm run db:push`    | Apply Alembic migrations       |
| `npm run db:migrate` | Autogenerate a migration       |
| `npm run db:seed`    | Insert sample data             |

## Ports

- API server: `3000` (uvicorn in the `dev:server` script)
- Client dev server: `5173` — proxies `/api` requests to the API server

## Database

SQLite — no Docker needed. The database file lives at `server/data/app.db`
(auto-created); `npm run db:push` applies the Alembic migrations.

## Environment

`server/.env` (created from `server/.env.example`) holds `DATABASE_URL` and
`CORS_ORIGIN`, read by `server/app/config.py` via pydantic-settings.
