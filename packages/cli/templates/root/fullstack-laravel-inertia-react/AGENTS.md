# AGENTS.md

Guidance for AI coding agents working in this repository. Generated by OmniCraft.

## Stack

| Layer          | Tech                                    |
| -------------- | --------------------------------------- |
| App and UI     | Laravel 13 + Inertia + React + TypeScript |
| Database       | SQLite + Eloquent                       |
| Authentication | {{authSetup}}                           |

`server/` is the whole application; the root `package.json` only wraps
convenience scripts. OmniCraft retrieves the official pinned Inertia React
starter kit and prepares Composer dependencies during scaffolding.

## Commands

| Command              | What it does                                |
| -------------------- | ------------------------------------------- |
| `npm run dev`        | Run the Laravel dev server (prints its URL) |
| `npm run build`      | Build the Vite production assets            |
| `npm run db:migrate` | Run the database migrations                 |
| `npm run test`       | Run the Laravel test suite                  |

## Database

SQLite — the database file lives at `server/database/database.sqlite`; run
the migrations with `npm run db:migrate` (or `php artisan migrate` inside
`server/`).

## Environment

`server/.env` is prepared during scaffolding (including `APP_KEY`); the
database connection is `DB_CONNECTION=sqlite`.
