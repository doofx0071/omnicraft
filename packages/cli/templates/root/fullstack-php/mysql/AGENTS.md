# AGENTS.md

Guidance for AI coding agents working in this repository. Generated by OmniCraft.

## Stack

| Layer    | Tech                                            |
| -------- | ----------------------------------------------- |
| Client   | {{clientFramework}} + Vite + {{clientLanguage}} |
| API      | Laravel 12 + Eloquent (`server/`)               |
| Database | MySQL                                           |

The Laravel server is created with Composer during scaffolding; the root
`package.json` scripts wrap the artisan/npm commands.

## Commands

| Command              | What it does                   |
| -------------------- | ------------------------------ |
| `npm run dev`        | Run client and server together |
| `npm run dev:server` | Run only the Laravel API       |
| `npm run build`      | Build the client               |
| `npm run db:push`    | Run the Laravel migrations     |
| `npm run db:seed`    | Insert sample data             |

## Ports

- API server: `3000` (artisan serve in the `dev:server` script)
- Client dev server: `5173` — proxies `/api` requests to the API server

## Database

MySQL runs via Docker: `docker compose up -d` (credentials in
`docker-compose.yml` match `server/.env.example`), then `npm run db:push` to
run the migrations.

## Environment

`server/.env` (created from `server/.env.example`; OmniCraft runs
`php artisan key:generate` during scaffolding) holds `DB_CONNECTION`,
`DB_DATABASE`, and `APP_KEY`.
